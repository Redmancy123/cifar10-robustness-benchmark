# 实验协议与分析边界

## 研究问题

相同轻量网络在干净测试集上取得相近的分类准确率时，训练增强与一致性约束能否改善其对常见图像退化的鲁棒性？逐步引入一致性损失是否优于固定权重？

## 数据与划分

CIFAR-10 官方训练池共 50,000 张，按类别固定划分为 45,000 张训练与 5,000 张验证；划分种子 20261117。官方测试集 10,000 张仅用于最终评价。训练种子为 17、29、43，所有方法共用划分与评价协议。CIFAR-10-C 使用 15 种退化，每种 5 个强度，每个条件包含 10,000 张图像。

75 个条件是同一批基础测试图像的不同退化版本，不代表 750,000 个相互独立的新样本。测试结果未用于超参数搜索或验证集模型选择。

## 模型与共同设置

- CIFAR preactivation WRN-16-2，691,674 参数，dropout 为 0，从随机初始化训练。
- 100 轮，batch size 64，SGD，初始学习率 0.05，momentum 0.9，Nesterov，weight decay 0.0005。
- 前 5% 训练步进行学习率预热，之后 cosine 降至基础学习率的 0.001 倍。
- 图像归一化至 [-1, 1]；共同基础增强为 padding 4 的随机裁剪和随机水平翻转。
- 使用 AMP；验证与测试指标采用完整样本计算。最终权重取干净验证集 NLL 最低的轮次。

## 五组训练策略

| 标识 | 内容 |
|---|---|
| erm | 基础增强与交叉熵 |
| mixup | alpha=1，批次级采样混合比例，混合图像与监督目标 |
| augmix | 三分支、随机深度 1–3、训练严重度 3；基础视图交叉熵 + 两个独立增强视图与基础视图之间的 JSD，权重 12 |
| warmup | 与 augmix 相同的视图和计算，JSD 权重在前 20% 训练步从接近 0 线性升至 12 |
| matched | 固定 JSD 权重约 10.7999148，等于 warmup 实际离散调度权重的平均值 |

`matched` 控制的是预设权重的时间平均，不是实际累计 JSD 或梯度大小，不能据此证明唯一作用机制。标准 AugMix/MixUp 是已有方法，权重调度比较属于本工程的有限扩展，不是新架构或 SOTA 声明。

## 指标

每个条件计算全局混淆矩阵上的 Accuracy 与 Macro-F1、平均负对数似然 NLL，以及 15 个等宽置信度区间的 top-label ECE。退化汇总为各条件指标的算术平均；ECE 并非合并全部条件后重新计算。最终均值与样本标准差以三个训练种子为单位计算。CSV 内 Accuracy、F1、ECE 为 [0, 1] 比例；配对差值的 delta_pp 为百分点，时间为秒。

## 主要观察

1. 干净准确率在 93.34%–93.81% 之间，退化准确率却在 69.76%–86.23% 之间，干净性能不足以刻画退化鲁棒性。
2. AugMix 相对 ERM 的退化准确率增加 16.36 个百分点，但单次训练时间增加到约 2.7 倍。这是相同轮数的策略比较，不是同计算预算比较。
3. warmup 相对标准 AugMix 的种子配对差值分别约 +0.058、-0.006、+0.271 个百分点；均值 +0.108，样本标准差 0.145。证据不足以支持稳定改善。
4. warmup 相对 matched 的平均差值约 +0.351 个百分点，三个种子均为正，但仅有三个重复，不能声称统计显著性或机制得到证明。

## 运行记录与局限

全部 15 个正式 v1.2 运行均完成 100 轮，产生 1,140 条评价记录。冻结配置短哈希为 `7e8f423031`。旧版尝试因 AMP 累计跳步阈值产生误报，未纳入本次正式统计；v1.2 改为连续跳步与窗口跳步率监控后，全部方法从头重新训练。原实验目录保留旧版诊断，发布附件只收录成功的 v1.2 矩阵。

运行监控在 GPU 温度达到 80°C 或可用内存不足时请求暂停，在冷却至 72°C 且可用内存恢复后继续；85°C、心跳失效或监控持续失败会停止本项目拥有的进程树。这是保守的软件监控，不构成硬件绝对安全保证。显存 allocator fraction=0.5 仅限制 PyTorch 分配器，不是整个 GPU 进程显存的硬上限。

结果只覆盖一个数据集、一个网络规模、三个种子和常见退化。未研究对抗攻击、开放集识别或真实部署分布，也没有证明相同算力预算下仍存在相同幅度的收益。图 F09 是按固定遍历顺序选取的说明性案例，不是随机抽样或统计结论。
