# 数据、方法与实现来源

| 来源 | 本工程的使用方式 |
|---|---|
| [CIFAR-10 官方页面](https://www.cs.toronto.edu/~kriz/cifar.html) / Krizhevsky, 2009, Learning Multiple Layers of Features from Tiny Images | 官方训练与测试数据；按官方文件校验值下载，不在仓库中重新分发原始数据 |
| [CIFAR-10-C](https://zenodo.org/records/2535967) / [Benchmarking Neural Network Robustness to Common Corruptions and Perturbations](https://arxiv.org/abs/1903.12261), Hendrycks & Dietterich, ICLR 2019 | 常见退化评价数据与任务定义 |
| [mixup: Beyond Empirical Risk Minimization](https://arxiv.org/abs/1710.09412), Zhang et al., ICLR 2018 / [作者示例](https://github.com/hongyi-zhang/mixup) | 输入及目标的凸组合方法；alpha=1，不沿用他人成绩 |
| [AugMix: A Simple Data Processing Method to Improve Robustness and Uncertainty](https://arxiv.org/abs/1912.02781), Hendrycks et al., ICLR 2020 / [官方实现](https://github.com/google-research/augmix) | 增强算子语义、增强混合及三视图 JSD 训练；`src/data.py` 中相关算子根据官方语义改写，来源为 Apache-2.0，许可正文见 `third_party/AugMix-LICENSE` |
| [Wide Residual Networks](https://arxiv.org/abs/1605.07146), Zagoruyko & Komodakis, BMVC 2016 / [作者仓库](https://github.com/szagoruyko/wide-residual-networks) | 网络架构参考；本工程使用轻量 preactivation WRN-16-2 |
| [PyTorch GradScaler 2.5.1](https://github.com/pytorch/pytorch/blob/v2.5.1/torch/amp/grad_scaler.py) | AMP 动态缩放与跳步行为的工程参考 |

训练调度、确定性样本增强、固定划分、权重预热/平均权重对照、监控和统计流程在本工程中组织实现。参考仓库用于方法与实现语义核对；未把其训练结果作为本工程结果。当前配置参考 AugMix CIFAR 默认 100 轮，所有方法统一使用 100 轮，并非各原论文的完整复现配置。

外部数据与第三方内容遵循各自的使用条款。第三方许可并不自动为本仓库全部代码授予同一种许可；本仓库未另行选择整体开源许可证。
